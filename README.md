# MATCELI-API
Frontend y Backend del sitio web Matceli

Frontend: Vista pública para personas en general, donde se muestra la información y el detalle de las categorías y los productos
Backend: Vista privada, solo para usuarios administradores de la web, donde se podrá crear y actualizar las categorías y los productos

Implementación
Desarrollado con HTML, CSS, Python (Flask) + SQLite + CRUD, considerando un entorno virtual vnev
